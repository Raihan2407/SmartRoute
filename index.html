// KOMPLEKSITAS WAKTU
Dijkstra — Min-Heap Binary
T = O((V+E) log V)   S = O(V)
✅ Optimal untuk bobot ≥ 0
A* (A-Star) — f(n)=g(n)+h(n)
h(n) = Euclidean×0.40 [admissible]
T = O(E log V) avg   S = O(V)
✅ h admissible → A* optimal
BFS — Queue (FIFO)
T = O(V+E)   S = O(V)
❌ Abaikan bobot → bukan terpendek
// ANALISIS LANJUTAN
Analisis Amortisasi
Min-Heap push/pop: O(log n) worst case
Amortized per operasi: O(log n)
Total n operasi: O(n log n)
Recurrence Equation
Dijkstra via T(n):
T(V,E) = V·O(log V) + E·O(log V)
          = O((V+E) log V)

BFS    T=O(V+E)   S=O(V)
