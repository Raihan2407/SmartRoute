// ANALISIS LANJUTAN
Strategi Greedy (Dijkstra)
Tiap langkah pilih node dengan dist terkecil.
Keputusan lokal optimal → solusi global optimal.
Berlaku karena semua bobot ≥ 0 (non-negatif).
Analisis Amortisasi
Min-Heap push/pop: O(log n) worst case
Amortized per operasi: O(log n)
Total n operasi heap: O(n log n)
Recurrence Equation
Dijkstra T(V,E):
= V · O(log V) + E · O(log V)
= O((V+E) log V)
Time & Space Summary
BFS     T=O(V+E)    S=O(V)
Dijkstra T=O((V+E)logV) S=O(V)
A*      T=O(E logV)  S=O(V)
Brute Force (tidak dipakai)
Coba semua kemungkinan jalur.
T=O(V!) — tidak efisien untuk graf besar.
Dijkstra jauh lebih optimal.
Dynamic Programming (tidak dipakai)
DP cocok untuk masalah overlapping subproblem.
Shortest path sudah optimal dengan Dijkstra/A*.
DP (Bellman-Ford) dipakai jika bobot negatif.
Theory of Complexity
Shortest path ∈ P (polynomial time).
Dijkstra O((V+E)logV) — solvable efisien.
TSP (semua kota) ∈ NP-Hard — berbeda.
Masalah ini: P ✅ bukan NP-Hard.
Metrik Dijkstra A* BFS Terbaik
